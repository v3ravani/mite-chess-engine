# Contributing to Mite

Thank you for your interest in contributing to Mite.

## Reporting Issues
- Report bugs, crashes, and feature requests through GitHub Issues.
- For direct questions or private inquiries, you can contact the author at **viraj.ravani@somaiya.edu**.
- Provide clear reproduction steps, including FEN positions, move sequences, time controls, and platform details.

## Pull Requests & Code Guidelines
- Fork the repository, create a descriptive feature branch, and submit a pull request.
- Keep changes concise, focused, and verified.
- Ensure the code compiles cleanly with standard C compilers without warnings (e.g., `gcc -O3`).
- Test move generation, search stability, and UCI compliance before submitting.
- Report all test benchmarks and results honestly and completely, without omitting losses or unfavorable runs.

## Codebase Architecture
Although the source code is compact and concise, contributors can refer to [`ENGINE_NOTES.md`](ENGINE_NOTES.md) for a detailed explanation of the engine's architecture, data structures, search functions, and implementation.
