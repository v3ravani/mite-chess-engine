# Security Policy

## Supported Versions
Security fixes are applied to versions 2.0 and 1.x, as well as the current `main` branch.

| Version | Supported |
| :--- | :---: |
| 2.0.x | Yes |
| 1.x | Yes |
| < 1.0 | No |

## Reporting a Vulnerability
If you discover a security vulnerability, do not open a public issue. Report it privately by emailing **viraj.ravani@somaiya.edu** or via GitHub Private Vulnerability Reporting on this repository.

Please include:
- A description of the issue and potential security impact.
- Step-by-step reproduction instructions or proof of concept.
- Relevant system, compiler, and OS information.

## Responsible Disclosure & Executables
Please allow reasonable time for the maintainer to address the issue before public disclosure. Users should exercise caution when executing binaries from external sources and are encouraged to build from source code.
